# Robotics II

Robotics coursework centered on navigation and planning algorithms for environments that include geometric constraints and dynamic goals.

## Project

| Project | Description | Tools |
| --- | --- | --- |
| [Moving Target Visibility Graph](final_project/) | Construction and scaling evaluation of a visibility graph for intercepting a target following a known path. | Python, NumPy, Matplotlib |

## Concepts

- Polygonal obstacle visibility and collision checking.
- Time-augmented interception costs for moving targets.
- Empirical comparison of dynamic and traditional visibility-graph construction.
