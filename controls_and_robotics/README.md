# Controls And Robotics

Coursework in modeling, feedback control, mechatronic implementation, and robotic planning. The included projects move from transfer-function and state-space analysis to simulated hardware control and navigation for moving targets.

## Courses

| Course | Focus | Projects |
| --- | --- | --- |
| [Mechatronics](Mechatronics/) | Modeling and feedback control of electromechanical systems | Self-balancing Segway; magnetic levitation |
| [Modeling and Control of Dynamic Systems](Modeling_and_Control_of_Dynamic_Systems/) | System modeling and controller design | Nacho Supreme self-balancing toy |
| [Robotics II](Robotics_II/) | Motion planning in dynamic environments | Moving Target Visibility Graph |

## Methods

- Nonlinear equations of motion, numerical linearization, and state-space simulation.
- Transfer-function modeling, Bode analysis, root locus, and feedback-controller design.
- LQR control and Simulink hardware models.
- Visibility graphs and time-dependent target interception.

## Languages And Tools

MATLAB, Simulink, Python, NumPy, and Matplotlib.
