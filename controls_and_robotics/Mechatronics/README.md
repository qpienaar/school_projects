# Mechatronics

Mechatronics projects integrating electromechanical modeling, sensors, actuators, numerical simulation, and feedback-controller implementation in MATLAB and Simulink.

## Projects

| Project | Description | Tools |
| --- | --- | --- |
| [Self-Balancing Segway](segway/) | Nonlinear inverted-pendulum model with numerical linearization and LQR stabilization. | MATLAB, Simulink |
| [Magnetic Levitation](maglev/) | Solenoid and magnet model with sensor data, equilibrium linearization, and controller implementation. | MATLAB, Simulink |

## Concepts

- Nonlinear state models and numerical linearization.
- State-space feedback design and hardware implementation models.
- Experimental measurements for actuator and sensor characterization.
