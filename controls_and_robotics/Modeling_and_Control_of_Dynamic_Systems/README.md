# Modeling And Control Of Dynamic Systems

Coursework in dynamic-system representation and feedback design using transfer functions, frequency-response analysis, and closed-loop performance evaluation.

## Project

| Project | Description | Tools |
| --- | --- | --- |
| [Nacho Supreme](Nacho_Supreme/) | Controller design for a reaction-wheel self-balancing toy with current and IMU sensor models. | MATLAB, Control System Toolbox |

## Concepts

- Physical modeling of motor, reaction wheel, and inverted-pendulum dynamics.
- Sensor characterization through numerical Bode analysis.
- Cascade feedback design, step response, Bode response, and root-locus analysis.
